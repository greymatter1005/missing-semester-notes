What's a development environment? The tools you write software with. At its heart: a text editor, plus syntax highlighting, type checking, formatting and autocomplete. This lecture covers Vim, language servers, AI-powered development and IDE extensions.

01IDEs vs terminal workflows

Two ways to assemble the same capabilities. Learn the basics of both; master at least one.

IDE

e.g. VS Code — everything in one app

✅ Easier to learn
✅ Better built-in AI integration (e.g. AI autocomplete)
➖ Heavier; needs a GUI and installs

Terminal

tmux + Vim + Zsh + CLI tools

e.g. Ruff (Python linter/formatter), Mypy (type checker)
✅ Lightweight
✅ Sometimes the only option — no GUI, or you can't install software

👉
No preferred IDE yet? The lecturers recommend starting with VS Code.

02The Vim idea

Programmers spend most of their time navigating, reading and making small edits — not typing long streams of new text. Vim is optimized for exactly that mix.

🗣 The interface is a language

Keystrokes are commands with mnemonic names, and they compose — verbs act on nouns.

🖱 No mouse, no arrows

Both are too slow. Your hands stay on the home row; editing keeps pace with thinking.

🌍 Vim mode is everywhere

VS Code (VSCodeVim), Zsh (built-in), even Claude Code have a Vim mode. Learn it once, use it all over.

05Edits (verbs), counts & modifiers

Editing commands are verbs that act on movement nouns: [count] verb [modifier] noun.

Verbs

d{motion} delete · c{motion} change (delete + Insert) · y{motion} yank (copy)
x delete char (= dl) · s substitute char (= cl)
o/O new line below/above · p paste · u undo · Ctrl-r redo
~ flip case · J join lines

Counts & modifiers

3w 3 words forward · 5j 5 lines down · 7dw delete 7 words
i = inside, a = around:
ci( change inside parentheses · ci[ inside brackets · da' delete a quoted string incl. quotes

08Code intelligence & language servers

IDE extensions talk to a language server via the Language Server Protocol (LSP) to understand your code's meaning. e.g. VS Code's Python extension uses Pylance; Go uses gopls.

⌨️ Code completion

Type object. and see its real fields and methods.

📖 Inline docs

Documentation on hover and in suggestions.

🎯 Jump to definition

From object.field straight to where field is defined.

🔗 Find references

The reverse: every place a field or type is used.

📦 Import help

Organize, remove unused, flag missing imports.

✅ Code quality

Formatting, linting and type errors as you type (more in the Code Quality lecture).

Configuring them

Some languages work out of the box. Others need to know your environment — e.g. point VS Code at your Python environment so the server can see installed packages. Servers also have settings, like turning off static type checking for projects without type annotations.

09AI-powered development

Since GitHub Copilot (Codex, mid-2021), LLMs are everywhere in software engineering. Three form factors:

Suggests code at the cursor as you type. Steer it with names, docstrings and comments.

Vague name → vague guess
def extract(contents: str) -> list[str]:
    lines = contents.splitlines()
    return [line for line in lines if line.strip()]
Add a comment → what you meant
def extract(content: str) -> list[str]:
    # extract all Markdown links from the content
    import re
    pattern = r'\[.*?\]\((.*?)\)'
    return re.findall(pattern, content)
⚠️
Limit: it only writes at the cursor — so import re lands inside the function instead of at the top of the module. Better still: name it extract_links and write a docstring.

Select existing code, then ask for a change. Unlike autocomplete, it can rewrite what's there.

Selected code
import requests

def download_contents(url: str) -> str:
    response = requests.get(url)
    return response.text
Prompt: “use built-in libraries instead”
from urllib.request import urlopen

def download_contents(url: str) -> str:
    with urlopen(url) as response:
        return response.read().decode('utf-8')

Agents that plan and carry out multi-step changes across a project. Covered in depth in the course's Agentic Coding lecture.

Tools

Popular AI IDEs: VS Code + GitHub Copilot (free for students, teachers and maintainers of popular open-source projects) and Cursor. The space moves fast, and the leading products are roughly equivalent.
